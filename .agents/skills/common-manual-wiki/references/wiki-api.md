# 위키 API 사용 시 추가 확인

접속·인증·권한·원문 보존·충돌 방지·저장 검증은 [common-manual-wiki](../SKILL.md)를 따른다. UI로 충분하면 별도 API 도구를 만들지 않는다. 현재 환경에서 문서화되어 있고 권한이 확인된 위키 API를 쓰는 경우에만 다음을 점검한다. 확인하지 않은 첨부 스크립트나 API를 추측해 실행하지 않는다.

- 검색 결과 ID가 실제 페이지 ID와 같다고 가정하지 않고 대상 경로와 상세로 재확인한다.
- 페이지 목록과 상세 조회의 지원 필드는 다를 수 있다. 본문·에디터는 상세에서 확인하고, 페이지 ID는 현재 대상의 경로·상세로 확인한다. 예제의 고정 ID를 재사용하지 않는다.
- update에는 `content`와 `tags`를 함께 전달하고 기존 태그·게시 상태 등 변경 대상이 아닌 속성을 보존한다. `content` 생략 시 본문이 유지된다고 가정하지 않는다. 현재 API 계약이 불명확하면 임의의 쓰기로 시험하지 않고 지원되는 UI로 처리하거나 미확인 항목을 보고한다.
- update의 `editor` 변경만으로 전환이 완료된다고 판단하지 않는다. 전환이 필요하면 별도 승인 범위와 실제 지원되는 convert 절차·복구 가능성을 확인하고 콘텐츠와 렌더링을 재검증한다.
- 실패 응답 후에는 실제 반영 여부부터 조회한다. 페이지 생성·수정을 무조건 재시도하지 않는다.
